PART A (core work, branch core/ocean-transport, in your worktree)
One shared ocean-transport component, used by every drift-dependent module: debris drift (yours), Pleiades, and later the aerial surface-search module.
- It is a new core spoke, crates/ocean, depending only on geo. It contains:
  - a gridded current/Stokes/wind field loader, with its binary layout documented the way crates/flight/src/environment.rs is;
  - transport: RK2 on WGS-84, with velocity = current + k·Stokes + windage/leeway, plus diffusion or a random walk;
  - land and coast handling on a high-resolution coastline;
  - a runner subcommand or tool that builds drift products for those modules.

  Agree the product with thr_4pbhvf3sxi before building it.

PART B (hypothesis work, branch hypothesis/debris-drift, only hypotheses/debris-drift/)
The log-likelihood of the recovered-debris evidence given the impact location.
- The source region is 2-D around the 7th arc, ±100–150 NM. Pete: "the arc itself is an unlikely source". The end-of-flight stage supplies impact locations.
- Output: a smooth, normalised likelihood with explicit model error.
- One likelihood per ocean model, a shared alternative named "ocean-model".
- Pete wants the drift estimate on its own first, then integrated. He takes "PDF" to mean a probability density, and wants PNGs he can view.

LEARNINGS
- Object response dominates. A Stokes factor of ×0.5, ×1 and ×1.5 moved the mode to 11.9, 18.0 and 34.9°S; changing the current product moved it only 1.2°. Integrate object response per object class inside the likelihood.
- Coastline resolution decides which paths survive: the 1:110m mask omitted Réunion.
- Multiplying rare arrival probabilities is dominated by Monte Carlo noise; floors and pseudocounts set the old modes. So:
  - one forward ensemble per source cell, shared by all finds;
  - find episodes, not objects;
  - smooth estimators, e.g. Miron-style transfer operators or an analytic spread.
- Weight results by termination to avoid survivor bias. That caused the old "34°S" artefact.
- Drifter validation must split drogued from undrogued drifters.
- The expanded identity set is circular (8 of 11 additions cite CSIRO drift agreement), so use the stringent set.
- A uniform reporting rate cancels out. The Western Australia non-recovery term needs relative search effort by coast. Pete called WA non-recovery "important".
- Diffusivity was never tested: the old code used 100 m²/s, CSIRO a 5 NM/day random walk.
- The old final drift result (29.7–35.8°S, mode 30.7°S) was unconverged and lies north of the core estimate (35.9–39.5°S). The combined result will depend on drift's southern tail, so converge there.
- Aerial search: GA ArcGIS hosts 387 day-labelled AMSA polygons for 2014, but the licence is "still under review". They need drifted positions on those dates. Coordinate with the "Searched areas" thread.
