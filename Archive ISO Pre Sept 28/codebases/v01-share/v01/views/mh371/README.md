## Truth separation

The runner never reads the held-back truth file. Inference uses the exposed
source state, selected SATCOM and satellite projections containing no later
aircraft state, and the frozen ERA5/IGRF inputs. Only after the run artifacts
exist does the reporter open `mh371-truth.csv` to overlay later aircraft
positions and calculate per-epoch distance and coverage diagnostics.

This is runner-input truth separation, not a fully prospective blind-trial
claim. A pilot inspection moved the final selected window from 06:59 to 06:48
to avoid the known descent turn. That partly truth-informed experiment design
is recorded in the linked input-selection provenance and must accompany any
accuracy interpretation.

The truth file must not be used to tune the prior, choose a maneuver family,
set a fuel state, select a favorable seed, or discard a failed diagnostic.
MH371 has no exposed fuel anchor. Its source fuel and mass reuse the declared
MH370 source proxy as conditional priors rather than as an MH371 measurement.

## What the report tests

The report makes five initial lateral modes, four recurring-event rate
families, repeated lateral/speed/altitude events, independent-seed spread, and
particle/root genealogy visible. BTO-only and BTO-plus-BFO are shown as
separate scientific families.

The companion JSON, not this README, is authoritative for exact accuracy and
support values. One known flight can reveal failure or sensitivity, but it
cannot calibrate coverage for the unknown accident flight.

A passed `release-validation.json` means the binary, configuration, inputs,
complete snapshot set, reporter, truth identity, and rendered outputs close by
hash. It does not mean numerical support passed. Follow the report's watermark
and `numerical_support` object.

## Deliberate exclusions

The old “medium-BFO control” and `mh371_final_arc_bfo_sensitivity` files are not
included in this current view or result manifest. They were generated by a
constant-magnetic-heading model without the current multiple-mode,
recurring-event, and continuous powered-feasibility support. They cannot
validate this broad technique and must not be substituted when the broad
report is numerically unresolved.

MH371 is a computational control only. Its geography is not evidence about the
location of MH370.
