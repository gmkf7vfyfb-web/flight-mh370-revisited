# Embedded map background

`ne_110m_land.geojson` is the Natural Earth 1:110m land-polygon layer used
only as geographic context in generated reports. It does not enter the
estimator or any likelihood.

- upstream: https://github.com/nvkelso/natural-earth-vector
- commit: `ca96624a56bd078437bca8184e78163e5039ad19`
- path: `geojson/ne_110m_land.geojson`
- SHA-256: `9e0729ee253ca7d7a5c4ae9395fb1902264c5377c52e224d13dd85010e2835d9`
- coordinate reference system: OGC CRS84 longitude/latitude
- scale: 1:110 million

Natural Earth data are public domain.

`DejaVuSans.ttf` and `DejaVuSans-Bold.ttf` reproduce the typography used by
the earlier Matplotlib paper figures. The exact license is retained as
`DEJAVU-LICENSE.txt`.
