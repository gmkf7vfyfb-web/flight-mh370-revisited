# Published along-arc comparators

These values are author-reported source ranges, peaks, or reference points
used only as labelled context below the separate native-HYCOM and CMEMS
diagnostics. They are not mutually comparable posterior intervals and are
never pooled or treated as observations by the runner. The plot code reads
`inputs/published-drift-comparators.csv`.

The located primary PDFs are preserved in the read-only investigation archive
at `/jackbox/home/.iso/thread-storage/MH370-legacy-pre-refactor-20260824/corpus/papers/`.
The CSV pins each source by SHA-256 so the plotted values can be audited even
if that archive is moved.
