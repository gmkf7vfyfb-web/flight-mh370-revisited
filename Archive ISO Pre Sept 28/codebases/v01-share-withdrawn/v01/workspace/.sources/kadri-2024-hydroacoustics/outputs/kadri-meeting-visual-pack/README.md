# Kadri meeting visual pack

Open `index.html` for the browser-viewable briefing. `speaker-notes.md` contains the same slide order and copy. The `assets/` directory contains full-resolution PNGs and vector SVGs where available. `kadri-meeting-visual-pack.zip` is the portable download.

The pack is a presentation aid. It does not alter estimator weights or convert publication-trace diagnostics into evidence.
