Cruise filter recovery controls

4 of 4 independently generated data sets have completed both inference runs. Each run starts with 20,000 candidates. Updated 2026-09-09T19:51:52.119725+00:00.

Every route and noisy contact sequence was generated before inference began. The estimator receives the generated measurements and original environment, with no access to its generating route. Generating routes were accepted by an independent uniform draw against the same remaining-fuel-envelope probability used in inference. Acceptance uses no SATCOM measurement or noise value. This checks computation conditional on that envelope, not the physical validity of the fuel model or an exact exhaustion trajectory. The accident-specific initial proposal is disabled for this control. Three equal-log-width parts of the existing shared manoeuvre waiting-time prior retain separate numerical populations in each navigation mode. Their prior masses sum exactly to the original prior; the original command/timing guide and all physical assumptions are unchanged.

The left plot shows where the generating location falls in each computed coordinate distribution. With exact inference over repeated prior-generated data, these values would spread uniformly from zero to one. The right plot measures disagreement between the two independent numerical runs. Large differences expose limited sampling resolution; they do not prove which run is closer to the exact answer.

Each bar compares an independent pair. The original data sets were selected by their pre-existing indices, without selecting on their recovery results. Smaller disagreement is useful evidence about numerical variation; agreement alone cannot establish correctness.

Where histories lose support

The lines show the inverse concentration of weight among initial ancestors at each completed contact block, before its resampling. Descendants of the same initial draw count together. The dotted line marks the initial candidate count. A sharp fall locates loss of diversity; later resampling cannot recreate a lost ancestor. This is a diagnostic, not an independent sample count or a threshold for accepting a distribution.
