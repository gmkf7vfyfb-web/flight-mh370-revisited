Cruise filter recovery controls

4 of 4 independently generated data sets have completed both inference runs. Each run starts with 100,000 candidates. Updated 2026-09-09T19:26:55.383496+00:00.

Every route and noisy contact sequence was generated before inference began. The estimator receives the generated measurements and original environment, with no access to its generating route. Generating routes were accepted by an independent uniform draw against the same remaining-fuel-envelope probability used in inference. Acceptance uses no SATCOM measurement or noise value. This checks computation conditional on that envelope, not the physical validity of the fuel model or an exact exhaustion trajectory. The accident-specific initial proposal is disabled for this control. A single proposal-component choice covers all commands until the next physical contact. The complete mixture density is compensated once; event-time corrections stay separate. The command factor is bounded by5 perinterval, not percommand; this does not bound posterior concentration.

The left plot shows where the generating location falls in each computed coordinate distribution. With exact inference over repeated prior-generated data, these values would spread uniformly from zero to one. The right plot measures disagreement between the two independent numerical runs. Large differences expose limited sampling resolution; they do not prove which run is closer to the exact answer.
