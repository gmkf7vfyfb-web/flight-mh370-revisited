# Archive of the loose root folders (25 October 2026)

## What this folder is

This folder holds five folders that were at the root of the repository: `outputs/`, `output/`, `downloads/`, `handoff/` and `library_full_audit/`.
We moved them here with `git mv` on 25 October 2026. Git keeps their history. We did not delete or change a file.

## Where each file was before

`MANIFEST.tsv` gives one line for each file: the path before the move, the path after the move, the size in bytes, the SHA-256 and the result (moved or kept).
Use it to find a file that a note gives by its old path. We did not change the old paths in other notes.

## Files that we did not move

Two files stay at `library_full_audit/MH370/`: `mh371-acars.xlsx` and `MH371_EHM_Export.xls`.
They are restricted holdings in `Claude Science Project Sep 29/results/restricted-sources-ledger.md`.
Pete's decision of 9 October 2026 says that such material stays where it is.
Use them internally only. Record each use in the ledger. Do not publish them before the review.

## Registry
