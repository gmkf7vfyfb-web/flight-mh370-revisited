+## Committing (plumbing recipe; the sparse clones are blobless, so plain `git commit` is UNSAFE)
+```bash
+cd <clone>; export GIT_CONFIG_GLOBAL=/dev/null; B=<branch>   # hypothesis/hydroacoustics for code/data/prereg; claude-science-sep29 for results notes + coordination
+git fetch -q origin $B
+export GIT_INDEX_FILE=.git/index-commit; rm -f $GIT_INDEX_FILE
+git read-tree origin/$B
+git add --sparse <paths...>             # --sparse is required
+TREE=$(git write-tree); OLD=$(git ls-tree -r origin/$B | wc -l); NEW=$(git ls-tree -r $TREE | wc -l); [ "$NEW" -ge "$OLD" ] || { echo TREE SHRANK; exit 1; }
+C=$(git -c user.name="Hydroacoustic Module (<track>)" -c user.email="noreply@users.noreply.github.com" commit-tree $TREE -p origin/$B -m "<message>")
+git push -q "$URL" $C:refs/heads/$B || { git fetch -q origin $B; echo "RETRY: repeat from read-tree on the new head"; }
+```
