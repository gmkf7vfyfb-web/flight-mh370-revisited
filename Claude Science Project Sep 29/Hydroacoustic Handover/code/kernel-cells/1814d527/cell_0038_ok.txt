+for the collaboration with Dr Usama Kadri. **Status: PREDICTIVE, NOT CALIBRATED.** Nothing here is a detection claim.

+`CALIBRATION_STATUS.txt`. Both published H01W times are carried everywhere: "text time 00:52:03" and "caption time 00:54:30".

+## Running the reference measurement unchanged on IMS triad data
+
+1. Export one triad record to `.npz` with these keys: `t0_utc` (ISO string, start of the record), `fs` (Hz, 250 for IMS),
+   `x` (3 × N pressure in Pa, elements in a fixed order after instrument response removal), `lat`, `lon` (3 element
+   positions, degrees, same order). Any record length ≥ 5 min works; include at least 60 s before the window of interest.
+2. Choose the signal window `[w0, w1]` and a pre-event noise window `[n0, n1]`, both in seconds from `t0_utc`
+   (e.g. for the text time at H01W with a record starting 00:45:00: signal 390–480 s, noise 60–300 s).
+3. Run
+   ```
+   python reference_measure.py H01W_0045.npz 390 480 60 300 out.csv --m1b templates_envelope.npz
+   ```
+   Output: one row per band (2–5, 5–10, 10–20, 20–40, 5–40 Hz) with peak Pa, RMS Pa, exposure Pa²s, noise RMS, SNR dB,
+   back-azimuth, apparent speed, minimum inter-element cross-correlation, delay-fit residual; and, for 5–40 Hz, the M1b
+   maximum correlation coefficient in the window, its time, and the maximum in the noise window.
+4. Thresholds: none are supplied. The M1b statistic must be referenced to the station's own background (maxima of ρ over
+   60 s windows on quiet days; the 99th percentile is the α = 0.01 reference used in our trials). The self-test gives the
+   model-matched best case only (`selftest_summary.json`).
+5. Nothing else is needed: no project code, no network. `python synth_triad.py test.npz 256.8 0` makes a synthetic record
+   you can use to check the pipeline before touching data (requires `pulse_runj.npz` and the IMS `stations.csv` positions,
+   both in the zip).
