# Hydroacoustic source survey (23 Oct 2026) and next steps (24 Oct 2026)

Status: literature review, catalogue queries and exploratory analyses. Nothing here returns a likelihood to the composer. The standing caveats apply to every rejection or upper limit: (1) the propagation-model frequency-slope failure against the 2001 airguns; (2) detection probability is a proxy unless measured on real data.

Start with `impact-and-other-sources-synthesis-2026-10-23.md`, then `next-steps-2026-10-24/next-steps-results-2026-10-24.md`.
