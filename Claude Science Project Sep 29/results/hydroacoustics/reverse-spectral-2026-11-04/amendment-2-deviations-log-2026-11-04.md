# Amendment 2: deviations log (A2.11)

Date: 4 November 2026. Amendment 2 (commit 709b2da1) is not edited. Each deviation below has its date, its reason and its effect. Where a deviation was made after the arrival windows were opened, the results are given with and without it.

| No. | When | Deviation | Reason | Effect on results |
|---|---|---|---|---|
| 1 | before any arrival window was opened | Decision rule: a window with p(background noise only) >= 0.5 is labelled "background noise only" BEFORE the impact-like test. | An impact-like label needs a signal. Without this order, a pure-noise window that is broadband by chance would be labelled impact-like. | None on the S10 statistic or p-values. Labels only. |
| 2 | after the windows were opened | On envelope-only data (Kadri traces) the label "impact-like" is not assigned; such windows are "unclassified". | The rule needs "broadband", which an envelope cannot show. The first run assigned impact-like to Cape Leeuwin envelope windows with an impact-like probability of only 0.09-0.18. | Cape Leeuwin windows at 00:39:20, 00:39:33, 00:46:40 and 00:54:34 change from "impact-like" to "unclassified". Both labels are in `crosscheck_back_to_basics_cases.csv` (columns class_label and class_label_before_deviation_2). Raw IMOS labels are unchanged. |
| 3 | after the windows were opened | Section 8 timing association uses only the pre-registered known-event catalogue (commit 264a9a4) on paths that it does not class as blocked. The predicted arrival includes the catalogued rock leg at 3.5-8 km/s; the water leg uses 1.467-1.518 km/s. | The first pass used every catalogue event (including blocked paths, for example an ML 1.9 event in Taiwan whose path to Portland is blocked) and put the rock leg at water speed. No candidate is removed in either version. |
